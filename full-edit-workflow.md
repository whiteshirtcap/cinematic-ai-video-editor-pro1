# End-to-End Editing Workflow

1. Inventory all source media and inspect technical properties.
2. Watch the complete footage.
3. Transcribe the dialogue and align word timestamps where supported.
4. Review Malayalam spelling and uncertain words.
5. Create a semantic beat sheet.
6. Generate hook concepts and select an accurate one.
7. Build a rough cut and pacing map.
8. Add relevant B-roll, graphics and motion.
9. Design Malayalam titles and synchronized captions.
10. Correct image, match shots and apply a cinematic grade.
11. Clean dialogue and mix sound according to user instructions.
12. Render a review copy.
13. Watch the complete render and run QC.
14. Deliver the final file, project and subtitle files where supported.

## Edit decision list
When direct editing is unavailable, provide:
- In/out time
- Spoken phrase or story beat
- Edit action
- Visual treatment
- On-screen Malayalam text
- Sound cue
- Confidence / notes

Do not invent timestamps. Label estimates as approximate.

## Delivery report
Include duration, resolution, frame rate, aspect ratio, codec, audio settings, subtitle status, project location and known limitations. Only report a completed render after verifying it exists and plays.
