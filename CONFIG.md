# Configuration and quality gates

## Default delivery
- Primary: 9:16, 1080×1920, 30 fps
- Alternate: 4:5, 1080×1350; 16:9, 1920×1080
- Audio: stereo, 48 kHz where supported
- Captions: Malayalam-first, phrase-based
- Word highlighting: only for selected emphasis beats
- Safe margins: protect titles/captions from platform UI

## Visual defaults
- Style: premium cinematic podcast / documentary
- Lighting: balanced exposure, natural skin and subtle subject separation
- Grade: neutral correction first, restrained creative look second
- Motion: smooth easing and intentional camera emphasis
- Typography: bold Malayalam-capable font with tested glyph shaping

## Audio defaults
- Dialogue is the priority.
- No music when requested.
- Effects are subtle and synchronized.
- Avoid clipping and audible processing artifacts.

## Editing constraints
- Preserve all words unless the user authorizes cuts.
- Preserve meaning if removing pauses or filler.
- Never fabricate documentary evidence.
- Keep source media unchanged.
- Save a project version before major changes.

## Required QC gates
1. Transcript and proper nouns reviewed.
2. Malayalam glyph shaping and spelling checked.
3. Hook accurately represents the content.
4. Full audio reviewed.
5. Full video reviewed for glitches.
6. Export dimensions and frame rate checked.
7. Final file exists and plays before delivery.
